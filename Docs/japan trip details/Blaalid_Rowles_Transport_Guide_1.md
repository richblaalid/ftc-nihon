## 1. SmartEX App — Shinkansen (Bullet Trains)

| Detail | Info |
|--------|------|
| **What** | App for booking reserved Shinkansen seats. Change times for free, unlimited. |
| **Download** | iOS App Store or Google Play — search "SmartEX" |
| **Setup** | Register a credit card, verify account. **Do this at home** — setup can be finicky in Japan. |
| **Who** | Both families download and register on one phone each |
| **Booking split** | Phone 1 books 4 seats, Phone 2 books 3 seats (max 6 per reservation) |
| **Child fares** | Ages 6–11 = half price. Age 12 = adult fare. |
| **At the station** | Tap your phone at the Shinkansen ticket gate. Seats confirmed. Board. Done. |

## 3. IC Cards — For All Local Transit

| Detail | Info |
|--------|------|
| **What** | Rechargeable tap-to-ride cards for all local trains, subways, buses, and convenience stores |
| **Options** | **Suica** (JR East) or **Pasmo** (Tokyo Metro) — identical coverage, interchangeable |
| **iPhone** | Add Suica directly in Apple Wallet (Settings → Wallet → Transit Card → Suica) |
| **Android** | Google Pay → Transit → Suica |
| **No mobile wallet?** | Buy physical Welcome Suica at Haneda airport JR counter or any JR ticket machine (¥500 deposit) |
| **Initial load** | ¥5,000 per person on arrival day |
| **Reload** | Any station ticket machine, any convenience store (7-Eleven, Lawson, FamilyMart) |
| **Daily usage** | ~¥1,500–2,000/person/day on local transit |
| **Also works at** | Convenience stores, vending machines, some restaurants, coin lockers |
