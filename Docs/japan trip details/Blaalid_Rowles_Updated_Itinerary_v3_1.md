**Bamboo Grove swap:** Removed the main Arashiyama Bamboo Grove (over-tourism — often shoulder-to-shoulder). Replaced with bamboo-lined paths at Adashino Nenbutsuji in the quieter Sagano area. Same magical bamboo experience, far fewer crowds, and Mico describes this temple as "one of the most humbling places in Kyoto" — over 8,000 stone statues honoring Kyoto's forgotten souls.

**Rickshaw Booking:**
| Detail | Info |
|--------|------|
| **Company** | Ebisuya (main operator in Arashiyama) |
| **Website** | https://ebisuya.com/en/ |
| **Also available on** | Klook (search "Arashiyama rickshaw") |
| **Walk-up** | Possible — they station runners near Togetsukyo Bridge. But with 7 people you'll need multiple rickshaws, so pre-booking is recommended. |
| **When to book** | 1–2 weeks before the trip |
| **Duration** | Book the 1-hour course |
| **Route** | Request the Sagano route through smaller temples toward Adashino Nenbutsuji. This matches Mico's recommended route (Jojakko-ji, Gio-ji, Adashino area). |
| **Capacity** | Each rickshaw seats 2 adults or 1 adult + 1 child comfortably. For 7 people, you'll likely need 3–4 rickshaws. |
| **Cost estimate** | ~¥9,000–12,000 per rickshaw for 1 hour |

**Schedule impact of Kyoto changes:** The bamboo grove swap and Adashino addition actually improve the flow. Tenryu-ji without the grove walk-through is a focused 45-min garden visit (vs 75 min). The rickshaw naturally routes through Sagano to Adashino, so the temple slots in seamlessly after the ride. You arrive back in central Arashiyama for lunch at roughly the same time as the previous plan — no schedule compression needed.
